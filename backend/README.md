# yt-hoarder backend

FastAPI app plus an in-process task orchestrator driving yt-dlp downloads,
transcription, and clipping. See the repository root [README](../README.md)
for what the app does and [AGENTS.md](../AGENTS.md) for architecture,
invariants, and development conventions.

Quick start (from the repo root): `bash setup.sh` · day-to-day: `task help`.
